# Scripts de processamento

## Visão geral

Esta pasta está reservada na organização do projeto e atualmente contém apenas este README. Não há scripts de limpeza separados a executar aqui.

## Conteúdo

O processamento ativo está em [Article/05_preprocessing.qmd](../../Article/05_preprocessing.qmd): leitura dos dados brutos, elegibilidade, triagem C/IER, recodificação, base final e estatísticas descritivas. A partição calibração/validação é produzida ou recuperada na [seção 6](../../Article/06_estimation.qmd).

## Instruções de uso

Execute as etapas pelos QMDs, após a preparação indicada no README principal. Os produtos são documentados em [Data/IntermediateData/](../../Data/IntermediateData/README.md) e [Data/AnalysisData/](../../Data/AnalysisData/README.md). Os arquivos compartilhados efetivamente usados ficam em [DataAppendixScripts/](../DataAppendixScripts/README.md).
